# Homebrew Tap for VidNeat

Official Homebrew tap for [VidNeat](https://github.com/ravi923615/vidneatdowndesktop) — Modern, privacy-first YouTube & video downloader for macOS.

## Installation

```bash
brew tap ravi923615/vidneat
brew install --cask vidneat
```

## Updates

```bash
brew upgrade --cask vidneat
```
